## 🔧 Optional: Git Hooks

Want checks to run BEFORE you push? Set up Git hooks:

    npm run setup:hooks

This will:
    • Run verification before commits (pre-commit hook)
    • Run full checks before pushes (pre-push hook)
    • Catch issues before they reach CI
    • Save time and CI minutes

Skip hooks if needed (emergency use only):
    git commit --no-verify
    git push --no-verify

## ⚠️ Important Notes

    • CI only runs when TypeScript, test, or config files change
    • Branch protection is optional but recommended
    • Git hooks are optional but catch issues earlier
    • Warnings don't block merge, but should be reviewed
    • You can skip Git hooks with --no-verify (emergency only)


## 🆘 Troubleshooting

Problem: "npm run verify" fails
Solution: Check error messages, run individual checks:
    npm run type-check    # Find TypeScript errors
    npm test              # Find test failures

Problem: CI doesn't run on PR
Solution: 
    • Ensure workflow file is committed to main branch
    • Check CI/CD is enabled in repository settings
    • Verify you changed TypeScript/test files

Problem: Git hooks don't work
Solution:
    chmod +x .husky/pre-commit .husky/pre-push
    npm run setup:hooks

More troubleshooting → docs/HOW-TO-ENABLE-PR-CI.md
